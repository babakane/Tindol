# Tindol Patterns: The Architecture-First Knowledge Base

> **Human-Verified. Research-Grade. Production-Ready.**

Tindol Patterns is a curated collection of modern computing methodologies and implementation proofs. Unlike standard "awesome lists," every pattern here is verified by the [Tindol Expert Network](https://babakane.github.io/Tindol/expert-program.html) and paired with a **Live Implementation Proof (LIP)**.

---

## 🏛️ Core Methodology Tracks

### 🤖 [Agentic AI Architectures](./agentic-ai)
Moving beyond simple LLM wrappers.
*   **Patterns**: Multi-agent handoffs, state-machine agents, autonomous tool-use protocols.
*   **Focus**: Determinism, safety, and long-running process resilience.

### 📶 [Local-First & Offline Resilience](./local-first)
Architecting for data ownership and zero-latency.
*   **Patterns**: CRDT integration, IndexedDB sync strategies, PWA state hydration.
*   **Focus**: Conflict resolution, privacy-first storage, and disconnected operation.

### 🌿 [Green Computing & Efficiency](./green-computing)
Optimizing for energy and carbon impact.
*   **Patterns**: Cold-start reduction, data transfer optimization, energy-aware job scheduling.
*   **Focus**: Sustainability, cost reduction, and performance density.

## 🛡️ The "Research-Grade" Standard

Every pattern in this repository must satisfy the **Tindol Three**:
1.  **Peer-Reviewed**: Signed off by a verified expert in the field.
2.  **LIP-Compatible**: Accompanied by a `docker-compose` or one-click deployment proof.
3.  **Methodology-First**: Documented with the *why* (tradeoffs) before the *how* (code).

## 🚀 How to Use This Repository

1.  **Explore the Tracks**: Navigate into a category above to find specific architectural blueprints.
2.  **Read the Deep Dives**: Each pattern links back to the [Tindol Blog](https://babakane.github.io/Tindol/blog/) for extensive research context.
3.  **Run the Proofs**: Look for the `lip/` directory in each pattern folder to find runnable code.
